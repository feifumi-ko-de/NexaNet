# Flowchart Operasional NexaNet

Pelanggan membuka website
-> memilih PC dan jadwal
-> mengisi data reservasi
-> sistem mengecek bentrok jadwal
-> jika bentrok: pilih jadwal lain
-> jika tersedia: sistem menyimpan reservasi
-> sistem menghasilkan kode booking
-> pelanggan datang ke warnet
-> admin mencocokkan kode booking
-> pelanggan membayar CASH
-> admin mengubah payment menjadi PAID
-> admin mengubah status menjadi CONFIRMED
-> pelanggan menggunakan PC
-> sesi selesai
-> admin mengubah status menjadi COMPLETED
